# 输出格式模板

从用户现有 Base 记录中提取的标准格式。写入新记录时必须严格遵循此格式。

## Base 字段格式

### 标题

纯日期数字，格式为 `M.D` 或 `MM.DD`：
- `6.1`、`5.30`、`4.9`

如果用户设置了自定义格式（如"日记6.1"），则按用户配置的格式生成。

### Done List

每条以 `✅ ` 开头（注意空格），动作+结果导向，多条换行：

```
✅ 参加XX课题组第一次组会，了解研究方向
✅ 修改论文第三部分初稿并发送给导师
✅ 去XX超市采购一周食材
✅ 整理书桌和工作环境
```

**写作规范**：
- 每条是一个完成的动作，不是泛化的描述
- 包含具体对象（人名、项目名、工具名等）
- **合并同类项**：同一件事即使被多次提及，也只合并为一条最精炼的描述
- 每条一行，用 `<br>` 或换行符隔开

### 灵感与感悟

每条以 `💡 ` 开头（注意空格），反思与洞察导向，多条换行：

```
💡 开始做之后发现任务没想象中困难——拖延往往是因为过度想象困难
💡 多输出内容时灵感反而更多，越不写越不知道写什么
💡 每周出门社交一次是很好的充电，比刷手机更能恢复精力
```

**写作规范**：
- 每条是一个独立的洞察或感悟
- **尽量摘录原话**：从逐字稿中直接引用用户的表达，只删掉口头禅和重复语气词，不要过度概括或改成书面语
- 包含因果逻辑（"因为……所以……"或现象→本质）
- 保持用户的口语风格，不刻意书面化
- 每条一行

### 关键词

逗号+空格分隔的 3-5 个关键词：

```
论文, 组会, 自媒体, 社交, 阅读, 内容创作
```

**选取原则**：
- 涵盖日记的核心主题
- 包含具体工具/平台/人名
- 不要超过 10 个

### 逐字稿摘要

一句话概括，纯文本，不加前缀符号：

```
参加课题组第一次组会，了解导师研究方向和同门课题；修改论文第三部分并发给导师；去超市采购一周食材；整理书桌和工作环境。
```

**写作规范**：
- 从逐字稿中提取最核心的 3-6 件事
- 用分号分隔
- 不需要完整句子，可以省略主语（默认主语是"我"）

### 妙记链接

完整的飞书妙记 URL：
```
https://<your-domain>.feishu.cn/minutes/<minute-token>
```

## 汇总文档追加格式

两个汇总文档使用飞书 Markdown 格式，按日期倒序排列（最新在最前）。

### Done List 汇总文档

```markdown
## 6.2 · 2026-06-02
- 完成 feishu-diary skill 编写，实现飞书妙记语音日记自动归档功能
- 测试 feishu-diary skill 归档效果，验证全流程可用

## 6.1 · 2026-06-01
- 参加课题组第一次组会
- 修改论文并发给导师
```

**规则**：
- 每条以 `## 标题 · YYYY-MM-DD` 开头（二级标题）
- 内容使用 `- item` 无序列表格式
- 每个日期块之间保留一个空行
- 新条目插入在最顶部（`str_replace` 替换第一个 `##` 标题实现）

### 灵感与感悟汇总文档

```markdown
## 6.2 · 2026-06-02
- 把重复性工作流固化为skill能极大提升效率——日记归档从手动变成一句话触发

## 6.1 · 2026-06-01
- 开始做之后发现没想象中困难——拖延往往是因为过度想象困难
- 多输出内容时灵感反而更多，越不写越不知道写什么
```

**规则**：同上，每条感悟以 `- ` 开头，不使用 `💡` 前缀（飞书渲染为 `<ul><li>` 列表）。
